# Upgraded Version

This release turns Hello World Atlas from a visual catalog into a small interactive programming-language museum.

## What changed

- Explore all catalog languages with live source previews
- Compare two languages side by side
- Learn through language passports and a Comment Atlas
- Play a Guess the Language mini-game with score and streak
- Preserve search, random discovery, source links, responsive design, and the two-comment convention

Release name: **Upgraded Version**
