# Upgraded Version

Hello World Atlas now behaves like a small interactive programming-language museum while keeping the original 52-language collection intact.

## Release highlights

- **Explore** — search/filter all 52 catalog entries, open the real source, copy code, and jump to GitHub.
- **Compare** — place any two languages side by side, swap them, or generate a random pair.
- **Learn** — language passports for popular languages plus a Comment Atlas that groups all catalog entries by native comment syntax.
- **Play** — a Guess the Language mini-game with four choices, score, and streak.
- **Hero** — rotating real source previews from the repository.
- **Responsive UI** — dark/light themes and layouts for desktop, tablet, and mobile.
- **No backend required** — static, fast, and easy to deploy.
