# Hello World Atlas — Website

The standalone static website for the Hello World Atlas.

## Local preview

Open `index.html` with a small static server (for example VS Code Live Server) so `catalog.json` can be fetched normally.

## Features

- responsive dark/light aesthetic
- searchable 52-language catalog
- category filtering
- random language discovery
- live source preview fetched from the repository
- one-click code copy
- direct GitHub file links
- keyboard shortcuts (`/`, `R`, `Esc`)
- no framework and no build step

## Deployment

Set the deployment root directory to `website` and deploy as a static site.
